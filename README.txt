# Personal Portfolio

## Files
- index.html - website structure/content
- style.css - design and responsive layout
- script.js - menu, typing effect, scroll reveal, validation, etc.
- resume.pdf - replace this with your real resume
- assets/profile.jpg - replace with your own profile photo
- assets/project-images/ - optional project images

## First things to edit
1. Replace "Your Name" with your real name.
2. Replace YOUR_LINKEDIN_URL, YOUR_GITHUB_URL and YOUR_FACEBOOK_URL.
3. Replace YOUR_EMAIL@example.com and your location.
4. Replace project demo/GitHub placeholders.
5. Replace the placeholder resume.pdf with your actual resume.
6. Replace assets/profile.jpg with your own photo.

Open index.html in a browser to preview the website.
